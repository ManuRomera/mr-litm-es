# MR- Legend in the Mist en español

Traducción completa al español de España del sistema oficial **Legend in the Mist** (`mist-engine-fvtt`) para Foundry VTT v13 y v14.

[![Descargas](https://raw.githubusercontent.com/ManuRomera/ManuRomera/main/badges/descargas/mr-litm-es.svg)](https://github.com/ManuRomera/mr-litm-es/releases)

**Instalación:** Add-on Modules → Install Module → Manifest URL:

```
https://github.com/ManuRomera/mr-litm-es/releases/latest/download/module.json
```

Requiere el sistema (≥ 14.5.4). Activa el módulo en tu mundo y pon Foundry en **Español**.

## Qué traduce

- **Interfaz:** las 487 cadenas de `es.json`, unificadas y corregidas.
- **Textos fijos:** ajustes, atajos, menús del editor, diálogos y avisos que el sistema escribe en inglés (`lang/literales.json`, aplicado al dibujar cada ventana).
- **Cómo jugar:** copia traducida de la plantilla (`templates/how-to-play.hbs`).

Ver `NOTICE.md` (derechos de los compendios, terminología) y `docs/GLOSARIO.md`.

Los compendios (pregenerados, documentación, libros de tema) **no** se traducen en este módulo.
